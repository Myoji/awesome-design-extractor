Responsive

Breakpoint Behavior

Desktop rules remain canonical; mobile evidence is represented as overrides for navigation, stacking, type scale, and rails.

Mobile390px baseline. Header collapses to menu icon, cards stack, rails shrink to 20-30px.
TabletNot deeply inspected. Treat as a transition between mobile stacks and desktop rails.
Desktop1440px baseline. 1340px product rail, 1090px utility content, 4-up model grid.
OverflowHorizontal tab rails scroll inside their own component instead of expanding the body.

Limitations

Evidence Boundaries

Authenticated owner flows, tablet breakpoints, deep configurator states, validation colors, and a site-wide dark mode were not observed. Synthetic CSS surface treatment replaces Genesis proprietary imagery; protected logo and hero references are evidence-only assets with reuse forbidden.
