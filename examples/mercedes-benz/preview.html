Responsive

observed
  • Header compacts from horizontal navigation into icon-led controls.
  • Hero stages crop vertically and stack copy/actions for narrow viewports.
  • Three-column catalog grids become one-column card stacks.
  • Filter-heavy flows should expose a compact filter entry before the list.
  • Footer columns stack while legal copy stays compact and aligned.

Limitations

observed
  • The global Mercedes-Benz page returned HTTP 403 in this environment; the official Korea site was used as the extraction source.
  • Authenticated account, payment, order completion, and dealer backend flows were not inspected.
  • Semantic success, warning, and error states were not observed.
  • Tablet and landscape breakpoints were not captured.
  • Synthetic CSS surface samples reconstruct layout and tone only; original marks and photography remain protected evidence references.
