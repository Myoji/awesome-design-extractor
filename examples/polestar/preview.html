Component States

primary / default

검정 채움, 흰색 텍스트, 오렌지 화살표.

outline / focus-visible

상태 근거가 약한 focus는 재현 가능한 CSS 상태로만 표시합니다.

filter / selected

선택 상태는 오렌지, 일반 상태는 투명 outline.

disabled / de-emphasized

비활성은 관찰 제한이 있어 faint text 계열로만 보수적으로 표현합니다.
